# Task 1

Create a free domain name service:

1. Sign up the https://freedns.afraid.org/signup/ webpage
2. Login and go to the https://freedns.afraid.org/subdomain/ page
3. Add a new subdomain
4. Fill the form: paste your GitHub page URL in the "Destination" field.

The custom domain will redirect to the GitHub page.

# Task 2

Create a free domain name service:

1. Sign up the https://freedns.afraid.org/signup/ webpage
2. Login and go to the https://freedns.afraid.org/subdomain/ page
3. Add a new subdomain
4. Fill the form: paste the EC2 public IPv4 address in the "Destination" field .

> Note: To create an Nginx webserver on the EC2 instance, visit the `static-site-server` or the `ec2-instance` project folder.
